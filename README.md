- # Retail Sales Prediction using ANN and Genetic Algorithm

## Description

This project compares the performance of a conventional Artificial Neural Network (ANN) and a Genetic Algorithm optimized ANN (GA-ANN) for retail sales forecasting using the Rossmann Store Sales dataset.

## Dataset

Rossmann Store Sales Dataset

https://www.kaggle.com/competitions/rossmann-store-sales

## Features

- Data preprocessing
- Feature engineering
- ANN baseline
- GA hyperparameter optimization
- Performance evaluation using:
  - MSE
  - RMSE
  - MAPE

- tensorflow
